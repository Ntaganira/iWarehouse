File format

Three columns: date, currency code, RWF for 1 unit. A header line is optional.

date,currency,rate
2026-10-06,USD,1448.10
2026-10-07,USD,1450.25
2026-10-07,EUR,1689.40
  • Commas, semicolons or tabs; 1450.25 or 1 450,25 both work.
  • Dates as 2026-10-07 or 07/10/2026.
  • All or nothing: if one line is wrong, no line is saved.
  • A line equal to a rate already recorded is skipped; a different value must be corrected on its own, with a reason.

Active currencies: USD, EUR, CNY
